# 📝 FastAPI Todo Application

A complete **Todo List Application** built using **FastAPI** for the backend and **HTML, CSS, JavaScript** for the frontend.  
This project demonstrates **CRUD operations**, **Pydantic validation**, and **animated UI** with real API integration.

---

## 🚀 Features

- Create Todo
- Get All Todos
- Get Single Todo
- Update Todo (Mark Complete)
- Delete Todo
- Request Validation using Pydantic
- RESTful API Design
- Animated & Responsive Frontend
- Auto-generated Swagger Documentation

---

## 🛠️ Tech Stack

### Backend
- FastAPI
- Pydantic
- Uvicorn
- Python 3.9+

### Frontend
- HTML5
- CSS3 (Animations & Transitions)
- JavaScript (Fetch API)
